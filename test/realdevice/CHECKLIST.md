# 実機テスト 手順書

> このファイルは `npm run realdevice:export` で作られます。手で直さず、`test/realdevice/scenarios.ts` を直してください。

## 使い方

1. Unity のプロジェクトに `scripts/` フォルダの `.js` をそのままコピーする（Assets の中ならどこでもよい）
   - Cluster Creator Kit が `.js` を自動で JavaScript Asset として読み込みます
2. シナリオごとに立方体などを置き、下の「Unity の準備」をする
   - スクリプトは Scriptable Item の **Source Code Asset** に `.js` をドラッグする
   - 向きを確かめるシナリオ（rd7・rd8・rd16）では、Item を付けたオブジェクトの青い矢印（Local 表示の +Z）が見えるようにしておく
3. ワールドを**アップロードして** Cluster で確かめる（テスト用スペースが便利）
   - Unity のプレビュー（エディタ内のプレビュー）では Scriptable Item が動かないので、プレビューでは確かめられません
   - エラーが出たかは、Cluster の「スクリプトログ」で見られます
   - rd15・rd16 は、ほかのプレイヤーがいない状態で行う（近くの誰にでも反応するため）
4. 下の一覧の「結果」に ○ / × を書く。× のときは実際の動きもメモして、Claude Code に伝える

Jcreate++ で中身を見たいときは、同じ名前の `.json` を `workspace読込` で読み込めます。

## シナリオごとの手順

### rd1 位置の即時反映

- スクリプト: `scripts/rd1-position-immediate.js`（ブロック: `rd1-position-immediate.json`）
- 確かめること: 同じイベントの中で2回続けて位置を変えたとき、2回目が1回目の結果から動くか（多くのブロックの前提）
- Unity の準備:
  - Item と Scriptable Item を付け、Source Code Asset に下のスクリプトを入れる
  - Movable Item を付け、Rigidbody の **Is Kinematic をオン**にする（スクリプトで動かすため。オフだと物理と取り合いになる）
  - 位置・回転・物理力をスクリプトから変更するため、このアイテムは移動可能/物理操作可能な設定が必要です。
  - インタラクト（クリック・使う）するには、アイテムにColliderが必要です。
- 操作: インタラクトを1回
- 期待する結果: **1 上がる**（0.5 × 2）
- 違ったら: 0.5 しか上がらない → 位置を設定した直後に読むと古い値が返る。「〜ずつ変える」を続けて使うブロック全般の前提が崩れる
- スクリプトの大きさ: 336 / 20,000 バイト（クラフトアイテムの上限）
