// ==== unity requirements ====
Unity側で必要な設定
- Item Audio Set List に "se" を登録してください。音を鳴らすには、このアイテムのItem Audio Set Listに同じIDの音を登録してください。
- サブノード "Label" に TextMeshPro コンポーネントを付けてください。文字を変えるには、指定したサブノードに対応するTextView/Text/TextMeshPro系コンポーネントが必要です。
- サブノード "Body" に MeshRenderer コンポーネントを付けてください。表示や当たり判定を切り替えるには、指定したサブノードに対応するUnityコンポーネントが必要です。
- サブノード "Lamp" に Light コンポーネントを付けてください。表示や当たり判定を切り替えるには、指定したサブノードに対応するUnityコンポーネントが必要です。
- インタラクト（クリック・使う）するには、アイテムにColliderが必要です。
// ==== code ====
// ── インタラクト時 ──
$.onInteract((player) => {
  // 音 se を 音量 0.8 で鳴らす
  {
    const audio = $.audio("se");
    if (audio) {
      audio.volume = 0.8;
      audio.play();
    }
  }
  // サブノード Label の TextMeshPro の文字を 「pressed」 にする
  {
    const node = $.subNode("Label");
    const textComponent = node && node.getUnityComponent("TextMeshPro");
    if (textComponent) {
      textComponent.unityProp.text = String("pressed");
    }
  }
  // サブノード Body の MeshRenderer を false にする
  {
    const node = $.subNode("Body");
    const component = node && node.getUnityComponent("MeshRenderer");
    if (component) {
      component.unityProp.enabled = false;
    }
  }
  // サブノード Lamp の Light を true にする
  {
    const node = $.subNode("Lamp");
    const component = node && node.getUnityComponent("Light");
    if (component) {
      component.unityProp.enabled = true;
    }
  }
});
