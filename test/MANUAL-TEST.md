# 全体テスト 手順書（手で確かめる分）

Web 版・ガイド・Unity 拡張・Cluster 実機を、ひととおり確かめるための手順です。
上から順に進めると、前の段階で作ったもの（`.js` や `.json`）を次の段階で使えます。

- 自動テスト（`npm test`・`unity/check`）で確かめられない、画面と実機の確認だけを書いています
- 実機の細かい手順は `test/realdevice/CHECKLIST.md`（自動で作られる手順書）を使います
- 結果は各表の「結果」に ○ / × を書きます。× のときは「5. 結果の伝え方」を見てください
- 時間が足りないときの順番: **4 の rd9・rd17・rd18 → 3-2 → 3-5 → 1 → 残り**

## 0. 準備

- GitHub の最新版（`c3b08d3` 以降）を ZIP でダウンロードして展開する
- Unity は、できれば **2021.3**（本来の対象で、まだ確かめていない）。無ければ 6000.2 で
- Cluster Creator Kit を入れた Unity プロジェクトを 1 つ用意する

## 3. Unity 拡張

### 3-1. 入れる

1. G2 の ZIP を展開して、中の `Jcreatepp` フォルダを Unity プロジェクトの `Assets` にコピーする
   - 前の版を入れていた場合は、先に古い `Assets/Jcreatepp` を消す（削除済みの `CoreEditorScript.cs`・`jcreatepp-toolbox.json`・`make-toolbox.ps1` とその `.meta` が残るとエラーの元になる）
2. Console にエラーが出ないこと、上のメニューに **Jcreate++** が出ることを確かめる

### 3-2. 自動テスト

1. `Window > General > Test Runner` → `EditMode` タブ → `Jcreatepp.Editor.Preview.Tests` を実行する
2. 全部緑なら OK
3. Console に出る `Jcreate++ core times: …` の行をコピーしておく（結果と一緒に送る）

## 4. Cluster 実機（rd1〜rd18）

### 手順

1. `test/realdevice/scripts/` の `.js` を全部、Unity の `Assets` にコピーする
2. `test/realdevice/CHECKLIST.md` の「シナリオごとの手順」のとおりに、シナリオごとに立方体を置いて準備する
   - 3-3 の U1（自動で付ける）を使うと早い
   - 回転を見るものは、上に小さな箱を乗せるなどして、向きが分かる形にしておく
3. ワールドをアップロードして入室し、`CHECKLIST.md` の一覧どおりに操作する（結果は `CHECKLIST.md` に書く）
4. Cluster の「スクリプトログ」にエラーが出ていないか見る

### 特に見るもの（ほかは CHECKLIST どおり）

| # | 正常 | メモすること |
|---|---|---|
| **rd9** | 90° 回るのに約 2 秒 | **かかった秒数**（遅いほど getter が遅れている。毎フレーム動かすブロック全体に関わる） |

| rd12 | 音が鳴り、文字が増える | 追加: わざと音の ID やサブノード名を間違えて、Cluster の画面とスクリプトログに何が出るか（3D プレビューでは成功してしまう） |

## 5. 結果の伝え方

- 各表と `test/realdevice/CHECKLIST.md` に ○ / × を書く
- rd9・rd18 は秒数も書く
- × のときは次を書く
  - 実際の動き（例: 「8 の字が 3 秒に 1 回ガクッと戻る」）
  - Console やスクリプトログのエラー（そのまま貼る）
  - Unity のバージョン
- 3-2 の `Jcreate++ core times: …` の行も一緒に送る
