# 更新履歴

前と動きが変わったときは、まずここを確認してください。
**「既存の作品への影響」** がある変更は、前に作った作品を開き直して JS を作り直すと、Cluster での動きが変わることがあります。

## 2026-10-14

### 既存の作品の動きが変わる変更

#### 「角度を〜だけ〜秒かけて回す」の回り方

- **変更:** 回り終わった向きが、同じ値の `角度を〜ずつ変える` と必ず同じになるようにしました。
- **影響がある作品:** アイテムが傾いた状態（x や z の角度が 0 でない）から回している作品。まっすぐ立った状態から 1 つの軸だけで回す作品（普通のドアやレバー）は変わりません。
- **元の動きにしたいとき:** 回したい最終的な角度を `角度を〜にする` で指定してください。

#### 「〜秒待つ」「N秒間、毎フレーム実行する」のタイミング

- **変更:** 待ち時間がフレームの速さによってずれていたのを直しました。`1秒待つ` を3回続けると、ほぼちょうど3秒になります（以前は処理が重いと 2.4 秒など早く終わることがありました）。秒数にマイナスを入れたときは 0 として扱います。
- **影響がある作品:** 待機を続けて使っている作品は、タイミングがわずかに変わります。

#### 「一連の動作」を2回目以降に動かしたとき

- **変更:** `一連の動作` を始めるたびに、その中の `もし〜になった瞬間` や「1回だけ送る」がリセットされ、2回目以降も反応するようになりました。
- **影響がある作品:** 一連の動作の中で `もし〜になった瞬間` を使い、条件が true のまま再実行していた作品。

#### フラグと真偽値変数が同じものになりました

- **変更:** `フラグ open` と `真偽値変数 open` は同じ値を指すようになりました。
- **影響がある作品:** 同じ名前のフラグと真偽値変数を、別のものとして使い分けていた作品。どちらかの名前を変えてください。

#### 小数の計算結果

- **変更:** 計算した結果を変数に入れる・比べる・表示するときに、有効数字15桁にそろえるようにしました。`0.1 + 0.2 = 0.3` は「等しい」になります（以前は「等しくない」）。「=」が近い値を同じとみなすことはありません。
- **影響がある作品:** 小数の計算結果を「=」で比べていた作品（多くは直感どおりの結果になる方向の変化です）。

#### 名前のチェックが厳しくなりました

- **変更:** フラグ名が空・`jpp.` や `__jpp_` で始まる・`true` / `false` の書き込みは、JS を作るときのエラーになります（以前は警告だけで JS が作られていました）。
- **影響がある作品:** そのような名前のフラグを使っていた作品。名前を変えてください。

#### 「一連の動作」の中の「衝突相手」

- **変更:** `衝突したとき` の `一連の動作` の中で衝突相手を使うと、JS を作るときのエラーになります。以前は JS は作られましたが、Cluster 上で毎フレームエラーになっていました。
- **対処:** 衝突相手への送信は、`一連の動作` の外（衝突した瞬間の処理）に置いてください。

### 表示が変わったもの（動きは同じ）

- **作られる JS が読みやすくなりました。** 各ブロックの前に日本語のコメント（例: `// 数値変数 score を 0 にする`）が入り、イベントごとに見出しが付きます。余分なかっこを減らし、値が決まっている計算（`1〜6 のランダムな整数` など）は短い式になりました。Cluster での動きは変わりません。

- `一連の動作（完了まで待つ）` → `一連の動作を始める（中を順番に実行）`。このブロックの後ろに置いたブロックは、中の完了を待たずにすぐ実行されます（以前からこの動きでした）。
- エラー文のかっこが二重（「「…」」）になっていたのを直しました。
- 「Unity側で必要な設定」に同じ文が何度も出ていたのを直しました。
- `現在位置から範囲〜へランダム移動する`・`保存した位置に戻る` だけを使ったとき、「Unity側で必要な設定」に移動可能（Movable Item）の設定が出ていなかったのを直しました。
- 編集中の警告と、JS を作るときのエラーの文が同じになりました。

### 新しい機能

- **3Dプレビュー:** 右側の `3Dプレビュー` タブで、作った動きを試せます。くわしくは [3Dプレビュー](./preview) を見てください。
- **3D で数値を編集:** ブロックを選んで、緑の箱をドラッグすると位置や角度の数値が変わります。
- **向いている方向に進む:** `向いている方向に 右/上/前 進む`、`〜秒かけて進む` ブロックを追加しました（[動作](./reference/motion#向いている方向に進む)）。
- **乗り物ギミックの「進む向き」:** `アイテムの前（+Z）` を選べるようになりました。前に作った作品は `従来（アイテムの左 -X）` のままです（[動作](./reference/motion#乗り物ギミック)）。
- **打ち間違いの警告:** 読んでいるのにどこでも値を設定していない変数、開始していないクールダウンに ⚠ が付きます。
- `サブノードの文字を〜にする` に、数値や計算のブロックをつなげるようになりました。
- **ブロックの動きの見本:** 左のブロック一覧で、動作のブロックにマウスを乗せると、動きの見本がツールチップの中で再生されます（[3Dプレビュー](./preview#ブロックの動きを見る)）。
- **部品を追加:** 3D プレビューの上から「回り続ける」「往復する」「触ると回る」「ドア」を選ぶと、ブロックが自動で入ります（[3Dプレビュー](./preview#部品を追加する)）。
- **スクリプトの大きさ表示:** 生成コードの上に、JS の大きさ（バイト数）を表示します。クラフトアイテムの上限（20,000 バイト）を超えると注意が出ます。ワールドに置くアイテムには関係ありません。
- **「Unity側で必要な設定」の追加:** 乗り物ギミック → Ridable Item と Seat、つかむイベント → Grabbable Item、インタラクト → Collider の案内が出るようになりました。
