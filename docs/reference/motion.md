# 動作

動作パーツは、アイテムやプレイヤーの位置、回転、速度を変えるためのパーツです。

## 動きを組み合わせる

同じアイテムの位置（または角度）を動かすブロックを2つ以上使うと、動きは足し合わされます。

- 例: `上下(Y) に往復する` と `左右(X) に往復する` を両方置くと、斜めや円・8の字のように動きます。
- 例: 往復しているアイテムに `位置を〜だけ〜秒かけて動かす` を使うと、往復したまま移動します。
- `位置を指定する` / `角度を指定する` は、その場所・向きにしてから、ほかの動きが続きます。

このとき作られる JS は、スクリプトが最後に決めた位置・向きを覚えておき、そこに足していきます（Cluster の `getPosition` は移動中の位置を返すので、読むたびに足すと前の動きが消えてしまうためです）。動かすブロックが1つだけなら、JS は今までと同じです。

足し合わせられない組み合わせは、ブロックに注意が出ます。

- `力を加える`（物理で動かす）と、ほかの位置を動かすブロック
- `追いかけるギミック`（毎フレーム向きを決め直す）と、ほかの角度を変えるブロック
- `毎フレーム` の中の `位置を指定する` / `角度を指定する` / `保存した位置に戻る` と、ほかの動き（毎フレーム決め直すので、ほかの動きが消えます）

注意は、イベントの中にあるブロック（と、そのまま置いたギミック）だけに出ます。どこにもつないでいないブロックは動かないので数えません。

手で持って動かしたあとは、離した場所から動きが続きます（`持ったとき` / `離したとき` のブロックがある作品）。

## 位置を指定する

アイテムの位置を指定した座標にします。

使いどころ:

- 初期位置へ戻す
- ドアを開いた位置へ移動する
- ゴールに着いたら場所を変える

注意:

- 大きすぎる値を入れると見えない場所へ移動します。
- 動かすアイテムはScriptable Itemとして動かせる設定が必要です。

## 位置を少し変える

今の位置から、指定した分だけ移動します。

使いどころ:

- 押すたびに少し動く
- 毎フレームでゆっくり進む
- ランダム移動の補助

## 位置を秒数つきで動かす

現在位置から、指定した差分だけ、指定秒数をかけて滑らかに移動します。

例:

- `位置を x:0 y:2 z:0 だけ 1 秒かけて動かす`

使いどころ:

- ドアをゆっくり開ける
- 足場を少しずつ動かす
- メッセージを受け取ったときに滑らかに移動する

注意:

- `毎フレーム` の中では使いません。
- インタラクト時やメッセージ受信時など、「動き始めるタイミング」に置きます。
- 指定する x / y / z は「最終的にどれだけ動くか」です。毎フレームの移動量ではありません。
- 動いている途中でもう一度始めると、その時点の位置から動き直します。
- `一連の動作` の中に直接置くと、動き終わってから次の手順へ進みます（`もし〜なら` などの中ではなく、一連の動作の中に直接置きます）。

## 向いている方向に進む

アイテムが向いている方向を基準に移動します。`位置を少し変える` は世界の x / y / z 方向に動きますが、こちらはアイテムの「右・上・前」に動きます。

例:

- `向いている方向に 右:0 上:0 前:1 進む`（今向いている方向へ 1 進む）
- `向いている方向に 右:0 上:0 前:2 を 1 秒かけて進む`

使いどころ:

- 角度を変えたあと、その向きへ進む乗り物や動物
- 向きがランダムなアイテムを「前へ」動かす
- 毎フレームの中で `前:` に `経過時間` を掛けた値を入れて、向いている方向へ進み続ける

注意:

- 「前」は `前方 〜m に〜がある`（レイキャスト）と同じ向きです。
- 後ろ・左・下へ動かすときはマイナスの値を使います。
- 秒数つきの方は、動き始めたときの向きで進む方向が決まります。途中で回転しても進む方向は変わりません。
- 秒数つきの方は `毎フレーム` の中では使いません。`一連の動作` の中に直接置くと、進み終わってから次の手順へ進みます（`位置を秒数つきで動かす` と同じです）。

## 角度を指定する / 角度を少し変える

アイテムの向きを変えます。

使いどころ:

- 看板を正面へ向ける
- 回転スイッチ
- 動く床の向きを変える

## 角度を秒数つきで回す

現在の角度から、指定した差分だけ、指定秒数をかけて滑らかに回転します。

例:

- `角度を x:0 y:0 z:90 だけ 1 秒かけて回す`

使いどころ:

- ドアをゆっくり回して開ける
- レバーを倒す
- 看板やギミックを演出つきで回す

注意:

- `毎フレーム` の中では使いません。
- インタラクト時やメッセージ受信時など、「回り始めるタイミング」に置きます。
- 指定する x / y / z は「最終的にどれだけ回すか」です。毎フレームの回転量ではありません。
- 回り終わった向きは、同じ値の `角度を〜ずつ変える` を1回使ったときと同じです（アイテムが傾いていても同じ）。
- 回っている途中でもう一度始めると、その時点の向きから回り直します。そのため、90度ずつのような区切りからずれることがあります。
- `一連の動作` の中に直接置くと、回り終わってから次の手順へ進みます。例: `90度 1秒で回す` → `2秒待つ` → `-90度 1秒で回す` で、回って、待って、元の向きに戻ります。

## 往復する

指定した軸方向へ、一定幅で往復します。最初の位置を中心に、サイン波（なめらかに行って戻る動き）で動きます。

- `幅`: 中心から片側への距離です。端から端までは幅の2倍動きます（幅 1 なら -1 〜 +1）。
- `速さ`: 速さ 1 で1往復に約 6.3 秒かかります。速さ 2 なら半分の約 3.1 秒です。中心で一番速く、端で止まります。
- ほかの往復や移動と一緒に使うと、動きが足し合わされます（[動きを組み合わせる](#動きを組み合わせる)）。

置ける場所:

- `毎フレーム`

使いどころ:

- 移動床
- 浮遊する足場
- 動く障害物

## 回転し続ける

指定した軸で回転し続けます。

置ける場所:

- `毎フレーム`

使いどころ:

- 回転床
- 風車
- 障害物

## 一定時間移動して戻る

指定方向へ一定時間動き、その後もとの位置へ戻します。

置ける場所:

- `毎フレーム`

使いどころ:

- 一定時間だけ開くドア
- せり上がる足場
- 押し出しギミック

## ランダムワープ

現在位置を中心に、指定範囲へランダムに移動します。

使いどころ:

- ランダム宝箱
- ワープ床
- 動き回る的

## 力を加える

アイテムに瞬間的な力を加えます。

使いどころ:

- 跳ねる物体
- 押し出される箱
- 衝突リアクション

注意:

- 物理の影響を受けるアイテムでないと見た目に出ないことがあります。

## プレイヤー速度 / ジャンプ速度を変える

イベントに関わったプレイヤーの速度倍率を変えます。

置ける場所:

- `インタラクト時`
- `持ったとき`
- `離したとき`

注意:

- 一連の動作の中では使えません。
- 速度を戻す処理も用意しておくと安全です。

## 乗り物ギミック

ワークスペースに置くだけで、乗って操作できる乗り物になります（イベントの中には入れません）。

- 前後キー: 進む / 下がる（`前進速度`）
- 左右キー: 旋回（`旋回速度`、1秒あたりの角度）
- 上下の操作: 上昇 / 下降（`上下速度`）

`進む向き` の選び方:

- `アイテムの前（+Z）`（新しく置いたときの標準）: Unity でアイテムの青い矢印（Z軸）が向いている方へ進みます。前方レイキャストや `向いている方向に進む` と同じ向きです。
- `従来（アイテムの左 -X）`: 以前のバージョンの動きです。前に作った作品は、開き直してもこの動きのままです。モデルの向きに合わせて、必要なら `アイテムの前（+Z）` に切り替えてください。

3Dプレビューでは `乗る` を押したあと、3D画面をクリックして W/S（↑↓）で前後、A/D（←→）で旋回、E/Q で上下に操作できます。
