# 通信

通信パーツは、別のアイテムへ合図を送るためのパーツです。

Jcreate++では、アイテム同士の連動を作るときに通信を使います。

## まずは「送る」だけで組む

条件なしの送信は、**動作**のブロックです。指定アイテム・近くのアイテム・送信元への返信・衝突相手への送信を、それぞれ値あり／値なしで選べます。

たとえば、クリックするたびにドアへ合図するなら次の2つだけです。

1. `インタラクト時`
2. 中に `指定アイテム door に メッセージ open を送る`

フラグや固定条件 true は不要です。送信先の World Item Reference List と、受信側の Scriptable Item は引き続き必要です。

条件付きにする場合は、送信ブロックを `もし` の中に入れます。

1. `インタラクト時`
2. 中に `もし フラグ 許可 がオン なら`
3. その中に `指定アイテム door に メッセージ open を送る`

この構成では、許可がオンの間はクリックするたびに送ります。条件を調べること、オン・オフを覚えること、合図を送ることは別々の役割です。

## 「毎回」と「成立した瞬間」の違い

| 組み方 | いつ送る？ |
|---|---|
| イベント → 送る | その動作が実行されるたび |
| イベント → もし → 送る | イベント発生時に条件が成り立てば送る |
| 毎フレーム → もし → 送る | 条件が成り立つ間、毎フレーム送る |
| 毎フレーム → もし〜になった瞬間だけ実行 → 送る | 条件が不成立から成立へ変わったときだけ送る |

「瞬間だけ」は、いったん条件が不成立になってから再成立すると、また送れます。一生に1回だけという意味ではありません。

## 保存済み作品と従来の送信

条件を持つ従来の送信ブロックも残っています。保存済み JSON を開いても、識別名・入力・動作を変更せず、そのまま読み込みます。

従来の近く・指定アイテム・衝突相手への送信は、毎フレームなどの繰り返し処理では条件が false → true になったときだけ送ります。インタラクト・受信・衝突など単発のイベントでは、条件が true のイベントごとに送ります。従来の返信は、条件が true の受信イベントごとに返す動作です。新しい送信ブロックへ自動変換はしません。置き換える場合は、上の表で送るタイミングを確認してください。

返信は受信イベントの中、衝突相手への送信は衝突イベントの中で使います。どちらも、時間をまたいで相手が使えなくなるのを避けるため、一連の動作の中では使えません。

## 受信イベント

メッセージを受け取って処理を始める入口です。

使うブロック:

- `メッセージ open を受け取ったとき`

置き場所:

- 左の `イベント｜開始/毎F/受信` カテゴリ

使いどころ:

- スイッチから `open` を受け取ったドアを開く
- 的あてで `hit` を受け取ったら音を鳴らす
- 別アイテムから点数を受け取って表示する

注意:

- 送信側と受信側のメッセージ名を完全に同じにします。
- `open` と `Open` は別の名前です。
- 受信側のアイテムにも Scriptable Item が必要です。

## 近くのアイテムへ送信

指定した範囲内のアイテムへメッセージを送ります。

使いどころ:

- 周囲のライトを一斉に点ける
- 近くのギミックをまとめて起動する
- エリアスイッチ

注意:

- 範囲が広すぎると大量送信になることがあります。
- `once` やクールダウンと組み合わせると安全です。

## 指定アイテムへ送信

World Item Reference Listに登録した名前のアイテムへメッセージを送ります。

使いどころ:

- スイッチからドアへ送る
- ボタンから表示板へ送る
- 中央制御アイテムへ送る

Unity側の準備:

- 送信先アイテムをWorld Item Reference Listに登録します。
- Jcreate++側の名前とUnity側の参照名を一致させます。

## 値つきメッセージ

メッセージと一緒に、数値、文字、真偽値、ハンドルを送ります。

使いどころ:

- 点数を送る
- ランダム結果を送る
- 開く/閉じるをtrue/falseで送る
- 衝突相手を別アイテムへ渡す

## 受け取った値

メッセージ受信イベントの中で、受け取った値を使います。

使いどころ:

- 受け取った数値を変数に保存する
- 受け取った文字を表示する
- 受け取った真偽値で表示を切り替える

注意:

- 受信値は `メッセージを受け取ったとき` の中だけで使えます。
- 一連の動作であとから使いたい場合は、受信直後に変数へ保存します。

## 送ってきた相手へ返信

メッセージを送ってきた相手に返信します。

使いどころ:

- 確認応答
- スイッチへ成功/失敗を返す
- 呼び出し元だけ反応させる

注意:

- 受信イベントの中だけで使います。

## 衝突相手へ送信

衝突した相手にメッセージを送ります。

使いどころ:

- ぶつかった相手だけ動かす
- 当たったアイテムだけ音を鳴らす
- ゴールに触れたプレイヤーやアイテムへ合図する

注意:

- `衝突したとき` の中だけで使います。
- 衝突相手が送信可能なハンドルでない場合は送信されません。
