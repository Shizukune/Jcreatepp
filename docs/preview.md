# 3Dプレビュー

Jcreate++ の右側にある `3Dプレビュー` タブで、作った動きを Cluster に持っていく前に試せます。

アイテムは赤い箱で表示されます。黄色い三角が **アイテムの前（+Z）** です。

## 開き方

1. ブロックを組みます（エラーがあるとプレビューできません）
2. 右側の `3Dプレビュー` タブを押します
3. `▶ 再生` を押すと時間が進みます

画面はドラッグで回転、ホイールで拡大・縮小できます。

## 画面の並び

上から **3D 画面 → イベントのボタン → タブ（状態 / ログ / 部品）** の順です。

### 3D 画面の上のボタン

| ボタン | すること |
|---|---|
| `⊕ 部品` | 部品タブを開く |
| `2m前にプレイヤー` | 箱の 2m 前にプレイヤーを置く（`範囲〜mのプレイヤー` や追いかけるギミックの確認用） |
| `3Dを大きく` / `元の大きさ` | 右側を広げ、3D 画面を大きくする（次に開いたときも覚えています） |

### 3D 画面の下（再生バー）

| ボタン | すること |
|---|---|
| `▶ 再生` / `⏸ 停止` | 時間を進める / 止める |
| `⏭` | 1フレームだけ進める |
| `⟲ リセット` | 最初からやり直す（`開始時` をもう一度実行） |
| `×0.25` 〜 `×4` | 速さ |

### イベントのボタン

作品で使っているイベントのボタンだけが出ます。

| ボタン | すること |
|---|---|
| `インタラクト` `持つ` `離す` `衝突` | そのイベントを起こす |
| `受信` | 選んだメッセージ名（作品にある名前）と値で `メッセージを受け取ったとき` を起こす。`その他（入力）` で好きな名前も送れます |
| `乗る` / `降りる` | 乗り物ギミックに乗る・降りる |

受信の値は、空なら「値なし」、`true` / `false` は真偽値、数字は数値、それ以外は文字として送ります（数字だけの文字は送れません）。

`開始時` はプレビューの準備時と `⟲ リセット` のときに、`毎フレーム` は再生中に動きます。

## 状態タブ

- 一番上に、アイテムの位置（m）と角度（度）が出ます。角度は 0〜360° の表し方に直しているので、何周回ったかは表せません
- 変数・フラグ・クールダウンは、種類ごとのカードで出ます
  - フラグ・真偽値は ON / OFF
  - クールダウンは残り時間と、残りの長さのバー
- 値が変わったカードは、少しのあいだ枠が黄色になります（クールダウンは、開始し直したときだけ）
- まだ値を入れていない変数は、最初の値（数値は 0、文字は空、真偽値は OFF）で出て、`初期値` と書かれます
- `⚠ どこでも設定されていません` と出る変数は、名前の打ち間違いかもしれません
- `一連の動作` は、どのイベントの中のものかと、いま何番目の手順か（例: `ステップ 2 / 4`）が出ます
- **カードを押すと、その変数を使っているブロックが左で黄色の枠になります**（値を変えるブロックは実線、読むだけのブロックは点線）。もう一度押すと消えます

実行中のブロックは、左のブロック画面で光ります。

## ログタブ

メッセージ送信・音・文字の変更・エラーなどが、起きた時刻（秒）つきで新しい順に出ます（最新 50 件）。

- ほかのタブを見ている間に増えた件数がタブに出ます。エラーがあると赤い印が付きます
- `ログを消す` はログの表示だけを消します（プレビューは続きます）

## 3D で数値を変える

次のブロックは、ブロックを選ぶと緑の半透明の箱が出ます。箱の矢印や輪をドラッグすると、ブロックの数値が変わります（元に戻すときは Ctrl+Z）。

- `位置を〜にする` / `位置を〜ずつ変える` / `位置を〜だけ〜秒かけて動かす`
- `向いている方向に進む` / `向いている方向に〜秒かけて進む`
- `角度を〜にする` / `角度を〜ずつ変える` / `角度を〜だけ〜秒かけて回す`
- `往復する`（幅）

注意:

- 数値ブロックがつながっているところだけ変わります。変数や計算がつながっているときは編集できません
- 「〜ずつ変える」などは、そのブロックが動く直前の位置・向きから表示します。まだ一度も動いていないときは、今の位置を仮に使います（画面に注意が出ます）

## 部品を追加する

部品タブ（3D 画面の `⊕ 部品`、またはブロック一覧の `部品｜自動でブロック` → `部品を選ぶ`）から、できあがった動きをブロックとして追加できます。部品を選ぶと動きの見本が出て、数値を決めて `ブロックを追加` を押します。追加されたブロックは普通のブロックなので、あとから中身を読んだり、数値を変えたりできます（元に戻すときは Ctrl+Z）。

| 部品 | 入るブロック |
|---|---|
| 回り続ける | `毎フレーム` に `〜軸を 速度〜で回転し続ける` |
| 往復する | `毎フレーム` に `〜方向に 幅〜 速さ〜で往復する` |
| 触ると回る | `インタラクト時` に `角度を〜だけ〜秒かけて回す` |
| ドア（開け閉め） | `インタラクト時` に、フラグとクールダウンを使った開け閉め一式 |

- `毎フレーム` や `インタラクト時` がもうあるときは、その中の最後に足されます
- フラグなどの名前は、もう使っている名前と重ならないように自動で決まります（例: `ドアが開いている2`）
- 位置や角度をもう動かしているブロックがあると、同じものを動かす部品は追加できません（動きがぶつかるため）。カードに「今は追加できません」と出て、選ぶと理由が出ます

## ブロックの動きを見る

左のブロック一覧で、動作のブロック（位置・角度・回転し続ける・往復する など）にマウスを乗せると、ツールチップの中で動きの見本が再生されます。

## 乗り物を操作する

`乗る` を押したあと 3D 画面をクリックすると、キーボードで操作できます。

- W / S（↑ / ↓）: 前進 / 後退
- A / D（← / →）: 旋回
- E / Q: 上昇 / 下降

## プレビューでは再現しないもの

プレビューは Cluster の動きを簡単にまねたものです。次のものは再現しません。

- 物理（`力を加える` はログに出るだけです）
- 他のアイテムやプレイヤーの実際の動き、通信相手の反応
- Cluster 上でのわずかなタイミングの違い

最後は必ず Cluster で動きを確認してください。プレビューで未対応の機能を使ったときは、画面に `プレビュー未対応` と表示されます。
